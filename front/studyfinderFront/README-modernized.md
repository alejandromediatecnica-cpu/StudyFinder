# StudyFinder — modernized UI

This version keeps the existing Angular routing and component structure, but refreshes the visual system around the supplied blue/black background.

Main changes:
- Glassmorphism sidebar and top bar.
- Supplied background image integrated as the main application backdrop.
- Cleaner blue/cyan visual system with reusable CSS variables.
- Responsive navigation for tablet/mobile.
- Redesigned Inicio, Materias, Calendario, Tareas, Study AI, Estadísticas and Configuración.
- Existing calendar navigation and Materias selection logic preserved.
- No new npm dependency is required for the UI redesign.

The ZIP intentionally excludes node_modules and Angular's generated cache. Run `npm install` in the project folder before `ng serve`.
